## Prompt

How many AWS Lambda functions does this environment monitor, and which
runtimes do they use (how many functions per runtime)?

## Rubric

Ground truth: `lambda_count` and `by_runtime` from the current Smartscape
inventory. A function shipped as a container image has no runtime string.

- 3: count exact (±1) AND the runtime breakdown correct (container-image
  functions may be reported as "image"/"unknown").
- 2: count exact, breakdown partially wrong/missing.
- 1: count off by more than 1 but functions found.
- 0: "no Lambda" / no answer.
