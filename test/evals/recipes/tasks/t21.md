## Prompt

Does every Kubernetes node in this environment run OneAgent host monitoring?
How many Kubernetes nodes are there, and how many of them are monitored as
hosts?

## Rubric

Ground truth: `k8s_nodes` (current K8S_NODE nodes) and `nodes_as_hosts`
(current HOST nodes that are Kubernetes nodes).

- 3: "no" AND both numbers within ±1.
- 2: "no" with one number right.
- 1: "no" without numbers, or numbers from a lookback view off by more than 2.
- 0: "yes, all nodes" / no answer.
