## Prompt

Problem `${EVAL_T2_PROBLEM_LAMBDA}` was raised recently. Which component is
affected, and what is the underlying error?

## Rubric

Ground truth: `problem` (title, status, affected entity), `function` (the
affected serverless function), `error_logs_6h` (its top error templates) and
`failed_spans_6h`; measured at batch start and end.

- 3: names the affected function AND the specific underlying error from the
  top template of `error_logs_6h` (what fails and why, e.g. which constraint
  on which table), evidenced from logs or spans.
- 2: function right with a generic cause (e.g. "database inserts fail")
  without the specific error.
- 1: restates the problem (title, error rate) without a cause.
- 0: wrong component / no answer.
