## Prompt

Which web frontend has the worst Interaction to Next Paint (INP) at the 75th
percentile for real users over the last 2 hours, and what is that p75 value in
milliseconds?

## Rubric

Ground truth: `ranking` lists web frontends by p75 INP (ms) over real-user page
loads with an interaction, measured at batch start and end.

- 3: the top frontend AND its p75 within ±35% of GT (either measurement).
- 2: right frontend, value off by >35% but same order of magnitude
  (e.g. interaction-less loads included), OR the runner-up when the top two are
  within 25% of each other with a correct value.
- 1: right frontend with a unit error (seconds/ns confusion) or no value.
- 0: wrong frontend / no answer.
