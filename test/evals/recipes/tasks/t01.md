## Prompt

Which Davis problems are open right now? Tell me how many problems are
currently open (ignore problems Davis marked as duplicates) and which problem
category has the most open problems.

## Rubric

Ground truth (latest state per problem, duplicates excluded): see `open_count`
and `by_category` (category → open problems), measured at batch start and end.

- 3: open count within the start–end range (±1) AND the top category correct
  (ties: any tied category).
- 2: count off by 2–3 OR the category wrong but the count right.
- 1: some open problems correctly listed, but count badly off (e.g. counts
  duplicates, or counts every problem updated in the window regardless of status).
- 0: wrong / no answer / "no open problems".
