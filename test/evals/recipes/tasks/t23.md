## Prompt

What is the most frequent ERROR log message in the last hour, and which
component or source emits it?

## Rubric

Ground truth: `patterns` — ERROR messages in the last hour grouped with
numbers masked, with counts and the emitting source (start and end of batch).

- 3: the top pattern (variants recognised as one message) AND its source.
- 2: the top pattern's message family without the source, or the source with
  a single numeric variant presented as the top message.
- 1: an ERROR message from the list that is not the top one.
- 0: wrong / no answer.
