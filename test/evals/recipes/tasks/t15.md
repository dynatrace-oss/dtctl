## Prompt

Which public clouds does this environment monitor through cloud integrations?
For AWS, Azure and GCP each, say whether any resources are present, and for
those present, roughly how many.

## Rubric

Ground truth: `aws`, `azure`, `gcp` resource counts in the current Smartscape
inventory (cloud resource node types).

- 3: AWS present with a count within ±25% (or counts by type summing to that)
  AND Azure absent AND GCP absent.
- 2: presence/absence correct for all three, AWS count missing or off.
- 1: one provider's presence wrong.
- 0: two or more wrong / no answer.
