## Prompt

Has this environment recorded any security attack or threat detections in the
last 7 days? If not, say what security data the environment does have.

## Rubric

Ground truth: `detections_7d` (expected 0) and `present_types` (security event
types that do exist, e.g. vulnerability and compliance findings).

- 3: "no detections in 7 days" established over the full 7d AND names at least
  one present security data type (vulnerabilities and/or compliance).
- 2: correct "no detections", but no statement of what is present, or a
  shorter window than 7d with a caveat.
- 1: "no detections" based on a short window only, without caveat.
- 0: claims detections exist / no answer.
