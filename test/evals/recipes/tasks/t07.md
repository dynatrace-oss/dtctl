## Prompt

How many input tokens did ${EVAL_T2_GENAI_MODEL} consume in the last 24 hours,
and across how many LLM calls?

## Rubric

Ground truth: `input_tokens` and `calls` after de-duplicating the spans that
record the same call twice; `naive_input_tokens` / `naive_calls` are the
doubled sums over every span of either spelling.

- 3: input tokens within ±25% of `input_tokens` (calls within ±25% if given).
- 2: tokens right but calls missing/wrong; or the agent reports both spellings
  separately with correct per-spelling numbers AND says they are probably the
  same traffic.
- 1: reports the doubled `naive_input_tokens` (±25%) as the answer.
- 0: wrong / no answer / "no data".
