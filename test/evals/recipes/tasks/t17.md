## Prompt

Which Kubernetes node has the highest CPU *requests* relative to its
allocatable CPU right now, and what is that percentage?

## Rubric

Ground truth: `ranking` of nodes by CPU requests / allocatable (%), over the
last 30 minutes, at batch start and end.

- 3: the top node AND percentage within ±5 points.
- 2: top node with a wrong/missing percentage, or the runner-up when within 3
  points of the top.
- 1: answers with CPU *usage* instead of requests, or a node in the top 4.
- 0: wrong / no answer.
