## Prompt

Which business event type was recorded most often over the last 24 hours, and
how many events of that type were there?

## Rubric

Ground truth: `top` lists event types with 24h counts (start and end of batch).

- 3: the top type AND count within ±20%.
- 2: right type, count off (e.g. a shorter window extrapolated, or ±20–50%).
- 1: right type with a count that is clearly the 2h default window, or the
  runner-up type.
- 0: wrong / no answer.
