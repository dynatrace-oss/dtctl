## Prompt

Did Runtime Application Protection detect attacks in the last 24 hours? Which
attack type was detected most often, and were those attacks blocked or only
monitored (audited)?

## Rubric

Ground truth: `by_type` lists RAP detections in 24h per attack type and action
(Blocked/Audited) with counts.

- 3: yes + the top attack type + its action correct (counts not required but
  must not contradict GT by more than 2×).
- 2: yes + top type correct, action missing or wrong.
- 1: yes, but top type wrong.
- 0: "no attacks" / no answer.
