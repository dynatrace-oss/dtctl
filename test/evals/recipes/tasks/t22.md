## Prompt

Did any workflow executions fail in the last 24 hours? If so, which workflow
failed, how many times, and when?

## Rubric

Ground truth: `failed` lists workflows with a final non-SUCCESS execution in
24h (title, state, count, last time); `executions_24h` the total.

- 3: names the failed workflow(s) with count and approximate time.
- 2: names the failed workflow, count or time missing.
- 1: says there were failures but cannot name them, or names a failure
  outside the window.
- 0: "no failures" / no answer.
