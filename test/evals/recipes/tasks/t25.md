## Prompt

Problem `${EVAL_T2_PROBLEM_RC}` was raised in this environment within the last
few days. What was its root cause, what evidence supports that, and what most
likely triggered it?

## Rubric

Ground truth: `problem` (title, root-cause entity, description with the
degradation figures), `evidence` (the events the problem links to, with the
root-cause-relevant flag) and `changes_2h_before_start` (change/deployment
events shortly before the problem started).

- 3: names the root-cause entity AND its degradation with numbers roughly
  matching `problem`/`evidence` (e.g. response time in seconds vs a
  milliseconds baseline) AND identifies the change event closest before the
  start (from `changes_2h_before_start`) as the likely trigger.
- 2: root-cause entity and degradation right, trigger missing or wrong; OR
  root cause and trigger right without any supporting numbers.
- 1: restates the problem title or lists affected entities without
  identifying the root cause.
- 0: wrong problem, "not found", or no answer.
